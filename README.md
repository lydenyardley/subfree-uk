# SubFree UK: video doorbells without a subscription

A hand-checked comparison of UK video doorbells: what's free, what's paywalled, and the 3-year cost with and without a plan.

Live page: https://lydenyardley.github.io/subfree-uk/

A single static HTML page, one content-versioned stylesheet and one content-versioned script, plus self-hosted product photos in `img/` (sources in `IMAGE_SOURCES.md`). No tracking, cookies, external fonts or third-party scripts. Prices change often, so check the linked sources before buying.

The compare selection lives in the URL. Tick two or three models and the address carries `?cmp=`, so the link and the shortlist text both reopen the same table.

## Rebuilding

Needs Python 3.10+ (built with 3.13). `build.py` uses only the standard library; images need Pillow; screenshots and the audit need Playwright, and the audit also needs `axe-playwright-python`.

```bash
git clone https://github.com/lydenyardley/subfree-uk.git
cd subfree-uk
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r build/requirements.txt
python -m playwright install chromium firefox   # needed for screenshots and the audit

python build/build.py            # rewrites index.html, the alias, 404.html, assets/page.*, data/doorbells.csv, data/doorbells.md
python build/make_images.py      # only if photos changed: rewrites img/, build/images.json, IMAGE_SOURCES.md
python build/shots2.py           # optional: screenshots at 1280/1000/900/820/390 + 1280 dark into screenshots/
python build/check.py            # rebuilds, then runs the full audit; exits 1 on any issue
```

`check.py` is the one command to trust before shipping. It rebuilds the site and fails if the generator changes a committed file, recomputes every derived figure from `ROWS` and compares it with the CSV, and checks that every open fact names its blocker. It then serves the repo on a loopback port, opens the page in Chromium, runs axe-core against WCAG 2.2 A and AA in both themes at 1280px, 820px and 390px, and checks internal anchors, image files, duplicate ids, labels, target sizes, the 11px type floor, the price range slider, the theme toggle's state, the filter and selection announcements, the empty-state nearest match and the filter that emptied it, the no-JavaScript fallback, the phone first screen and header association, the two 3-year figures lining up in every card, the photo lightbox, the 404 page, the printed columns, the bold figure that follows the sort, the linked prices, the details panel, the compare table caption and its 3-year cost row, the differences-only view, the focusable comparison scroller, the shortlist copy and its ?cmp= share link, the jump announcement, the tray-to-comparison transition and its focus handover, the hairline rule that follows the table's own scroll, the theme motion, the score-bar animation, the record and plan labels, the phone label column, the host-grouped source list, the closing line, the performance budget at 4x CPU throttle, and horizontal overflow at every breakpoint. Firefox then repeats the structural, layout and axe pass, so a Chromium-only fallback cannot hide a regression. It fails on axe's WCAG 2.2 A and AA violations; the best-practice rules axe also finds are reported as notes at the end of the run, so `region` and friends stay visible without turning a design decision into a red build. Add `--external` to request each outbound link over the network, `--list` to print the check names, and `--only "<name>"` to run one of them.

Spotted a mistake or a paywall change? [Open an issue](https://github.com/lydenyardley/subfree-uk/issues/new).

Scripts work from any directory. To use an installed Chrome instead of Playwright's Chromium, set `CHROME_PATH` (e.g. `CHROME_PATH=/usr/bin/google-chrome`).

## Pull requests

`.github/workflows/commits.yml` runs `build/check_commits.py` over every commit in a pull request and over every commit a push to `main` brings, because every commit here lands on `main` directly, so a message that breaks the format in [CONTRIBUTING.md](CONTRIBUTING.md) fails the check. `.githooks/commit-msg` runs the same rules before the commit exists; enable it once per clone with `git config core.hooksPath .githooks`. `.github/workflows/audit.yml` runs `build/check.py` on every pull request and every push to `main`, so a page that fails the audit cannot ship unnoticed. Run the same commands locally before opening one:

```bash
python build/check_commits.py origin/main..HEAD
```

To change data: edit `ROWS` / `S` in `build/rows.py`, run `python build/build.py`, check the page locally, then commit and push `main`. Pages redeploys in about a minute.
